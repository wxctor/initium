# INITIUM
O início de toda lenda.

Initium é uma plataforma criada para auxiliar mesas de RPG de forma prática e imersiva, reunindo combate tático, gerenciamento de campanhas e ferramentas para mestres e jogadores em um só lugar.

A ideia do projeto é tornar sessões online mais organizadas, dinâmicas e visuais, sem perder a essência do RPG de mesa.

# Funcionalidades
Combate em tempo real
Ordem de iniciativa
Fichas de personagem
Mapas interativos
Logs de sessão
Calendário de campanhas
Sistema multiplayer
Ferramentas para mestres

# Objetivo
O Initium foi pensado para facilitar a vida de quem joga RPG, oferecendo uma plataforma moderna para:
- organizar campanhas
- acompanhar sessões
- controlar combates
- registrar acontecimentos importantes
- conectar jogadores e mestres

Tudo isso com uma interface inspirada em fantasia sombria e sistemas táticos modernos.
